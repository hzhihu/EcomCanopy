# Phase 1 · 首页首屏方向比稿（第 1 轮）

状态：**待人工确认**（未选定方向，未进入正式 UI 开发）

三个方向共用同一套品牌文案与 Design Token 候选值，只改变**首屏结构与信息表达方式**。这样比较的是「哪一种讲法更清楚」，而不是配色偏好。

## 文件

| 方向 | 文件 | 方式 |
| --- | --- | --- |
| A 冠层 | `a-canopy-layers.html` | 左侧文案 + 右侧三层能力叠放（用递进色块表达「冠层」） |
| B 交付链路 | `b-delivery-chain.html` | 左侧文案 + 右侧四步交付链路（用节点与连线表达 FDE 流程） |

本地查看：直接用浏览器打开对应 `.html`，无依赖。

## 共识项（三个方向一致）

- 字体：中文系统字体栈（PingFang SC / 思源黑体 / 微软雅黑），英文 Inter。
- 主色：深墨绿 `#0F1F1A`；强调色：青绿 `#17866A`；底色：`#FCFBF8`。
- 无渐变、无发光、无装饰性插画。
- 深色只作为**一个块**出现（A 的第三层、B 的底部能力条），不做全站深色。
- 导航：8 项全平铺（首页 / 跨境 AI / AI Agent / 技术服务 / 项目 / 文章 / 关于 / 联系）。
- 字标：`EcomCanopy` + `易贸森 · 跨境 AI` 副标。

## 差异项

| | A 冠层 | B 交付链路 | C 编辑式 |
| --- | --- | --- | --- |
| 首屏传达 | 三层能力如何互相支撑 | 我怎么把 AI 落到业务里 | 主张 + 当前在做什么 |
| 图形语言 | 递进色块 | 节点与连线 | 无图形，靠字阶 |
| 信息密度 | 中 | 高 | 低 |
| 移动端表现 | 好（块状天然堆叠） | 中（链路变纵向长列表） | 好（字阶自适应） |
| 风险 | 三层色块容易被误读为「层级高低」 | 四步流程读起来像服务介绍，可能显得像外包 | 大标题方案对文案质量要求最高 |
| 与「不像大量卡片模板」 | 中 | 低（下方三列近似卡片） | 高 |
